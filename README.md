# 📖 Sobre o projeto

O **Atlas IT** é um projeto pessoal desenvolvido com o objetivo de criar uma
plataforma para **gerenciamento e controle de ativos de Tecnologia da
Informação**.

A proposta é centralizar informações que normalmente ficam distribuídas
entre planilhas, documentos e diferentes sistemas.

O projeto surgiu a partir de uma necessidade observada no dia a dia de um
ambiente de TI: conseguir consultar de forma rápida e organizada informações
sobre **colaboradores, equipamentos, softwares, licenças e movimentações**.

Além de resolver esse problema, o Atlas está sendo utilizado como um projeto
prático para aplicar e consolidar conhecimentos em **desenvolvimento backend,
C#, .NET, banco de dados e arquitetura de software**.

---

# 🎯 Objetivo

O principal objetivo do Atlas é oferecer uma visão centralizada dos recursos
de tecnologia de uma organização.

A plataforma pretende facilitar tarefas como:

- 👤 Identificar colaboradores;
- 💻 Controlar equipamentos;
- 🏷️ Controlar patrimônios;
- 🔗 Associar equipamentos aos colaboradores;
- 📱 Gerenciar celulares;
- 🖨️ Gerenciar impressoras;
- 💻 Gerenciar notebooks e computadores;
- 🧩 Controlar softwares e licenças;
- 🔄 Registrar movimentações de ativos;
- 📊 Disponibilizar informações para análise;
- 📝 Centralizar informações técnicas.
